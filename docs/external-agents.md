# 接入外部智能体

Claude Code、OpenClaw、Hermes、WorkBuddy 这类自带工具的智能体，也可以作为成员加入会话。不限于这几种：只要它能发 HTTP 请求（例如能执行 `curl`），就能接入。

## 怎么接

1. 「智能体」页 → 新建 → 「由谁来回答」选 **外部智能体**，选它是哪一种，起个名字，创建。
2. 窗口里会出现一条**连接指令**，点「复制指令」。
3. 把这段话整段粘贴到那个智能体自己的对话框里发出去。

它会读取说明并开始轮询，状态变成「已连接」后，就可以像普通智能体一样把它拉进会话、点名、让领头智能体给它分派任务。

## 本机命令行智能体

Claude Code、Kimi Code、Codex 这类装在本机的命令行智能体，选「命令行」方式并填上启动命令即可，轮到它时控制台直接调用，不需要它自己轮询。

- 输出边写边显示在会话里，旁边显示已用时间，不用干等。
- 「一轮最多等多久（分钟）」默认 15 分钟，写代码、跑测试这类大任务可以调大（最多 120）。超时或你点了停止，它和它启动的子进程会一起结束，会话里会说明原因。
- 它在会话自己的文件夹里工作；你发的附件就在其中的 `attachments/` 下。

## 它是怎么工作的（轮询方式）

- 轮到它发言时，控制台把它的身份、规则和最近的对话整理成一段文字放进它的任务队列。
- 它通过 `GET /api/ext/<口令>/next` 领取任务（最长等待 25 秒），完成后用 `POST /api/ext/<口令>/reply/<任务id>` 提交回复。
- 回复原样显示在会话里。它用自己的工具做事（例如 Claude Code 改代码），本控制台的「本地操作」审批不管它。
- 75 秒没有轮询视为离线；15 分钟没有回复则这一轮报错，会话继续。

## 注意

- 连接口令相当于这个智能体的身份凭证，泄露后别人可以冒充它提交回复。删除这个智能体口令即作废。
- 外部智能体需要能访问控制台的地址。它和控制台在同一台电脑上时，用 `localhost` 即可。
- 对方能不能一直保持轮询，取决于它自己：有的智能体在一轮对话结束后会停下来，需要你在它那边让它继续。
