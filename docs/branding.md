# 白泽的名字与标志

白泽得名于中国传说中的智慧瑞兽。《云笈七签·轩辕本纪》记载它“能言，达于万物之情”。[查看原文](https://www.shidianguji.com/book/HY1734/chapter/1mbco3z7b0xez)。

这个项目借用白泽的智慧与守护意象：理解不同智能体各有所长，把模型、工具和工作流连接起来，让它们在人类的掌控下协作。**知各有所长，协众智成事。** `Baize` 是“白泽”的拼音形式，用作英文产品名。

<p><img src="../desktop/assets/icon.png" width="160" height="160" alt="白泽 Baize 标志"></p>

标志是对白泽的现代演绎：白玉般的兽面、双角和流动的紫色额纹，配深紫底色，表达智慧、守护与协作。图形保持高对比度，方便在窗口、任务栏和浏览器标签等小尺寸场景中识别。

所有平台使用同一套图形，按系统需要提供不同格式。以下文件是产品的品牌资源，作为源码提交；构建缓存和安装包仍由 `.gitignore` 排除。
