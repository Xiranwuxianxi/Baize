# 协作方式

一个会话里有多个智能体时，可以在会话设置里选择它们怎么配合。只有一个智能体时就是普通的一对一对话。

## 接力发言 `sequential`

按会话里的顺序依次发言。轮到某个智能体时，它能看到之前所有人（包括本轮排在它前面的智能体）说的话。

- 「每次发送后自动进行 N 轮」大于 1 时，全员会在你发言后继续互相讨论 N 轮。
- 适合讨论、辩论、「先起草、再审查、再总结」这样的流水线。

## 并行作答 `parallel`

所有智能体基于同一份历史同时作答，彼此看不到对方本轮的回答。

- 适合对比不同模型，或让不同角色独立给出意见。
- 多轮时，每一轮开始前会取一次最新历史。

## 领头统筹 `lead`

你只和领头人对话，由它安排其他成员的工作。

```
你 ──► 领头人 ──分派──► 成员 A
                   └──► 成员 B
        领头人 ◄──结果── 成员 A、B
你 ◄── 领头人（审阅后的最终答复）
```

流程：

1. 领头人收到你的消息。它的系统提示词里附有成员名单和每个人的「一句话简介」。
2. 它可以直接回答；需要协作时，在回复末尾按下面的格式分派，每行一条：

   ```
   @成员名字：具体任务
   ```

3. 后端解析出分派清单，被点到的成员**同时开工**：每个人基于同一份上下文（你的需求 + 领头人的分派）各自完成自己的任务，互相看不到对方的中间结果，所以谁也不用等谁。成员只收到「完成这项任务」的指令。
   会话里这一轮显示为一个**任务看板**：每位成员一列，实时看到每个人的思考、操作（需要你批准的操作直接在列里批）、交付内容和状态（思考中 / 执行操作 / 等你确认 / 已交付 / 出错）。
   每一列右上角可以单独控制这位成员：进行中点「停止」只停它一个，其他人继续；这一轮结束后点「重做」，它会按同样的任务重新做一遍（出错时这个按钮会高亮）。
   有些任务环环相扣（B 要用到 A 的结果）：可以在会话设置的「协作方式」里改成「一个接一个」，或者让领头人分两轮派——它知道同一轮里的成员是并行的。
4. 成员都交付后，领头人统一审阅结果：可以继续分派，也可以直接答复你。
5. 「领头人最多分派 N 轮」用完后，它会被要求直接给出最终答复，不再分派。

细节：

- 解析对格式比较宽容：允许行首有列表符号、加粗、全角 `＠`，任务可以跨多行，同一成员被点到多次会合并。
- 只认名单里的成员；领头人不能给自己分派。
- 模型有时会用口语安排成员（「小王，请你……」）而不按格式写。首轮如果领头人提到了成员却没有按格式分派，系统会自动追问一次让它补上分派行。
- 如果一轮分派被你中途停止，之后让它继续（输入框留空直接发送）时，会先把没做完的任务补上，再请领头人审阅。
- 领头人需要能稳定遵循输出格式，建议使用能力较强的模型；成员可以用更小更快的模型。
- 写好每个成员的「一句话简介」很重要，领头人靠它判断该把任务派给谁。

### 总智能体：新会话的默认接待

在智能体设置里可以把一个全局智能体「设为总智能体」（同一时间只有一个）。之后点「新会话」会直接创建一个由它领头的会话，里面只有它一个人。

总智能体除了能给会话里的成员分派任务，还看得到所有**还没进会话的全局智能体**。它用同样的 `@名字：任务` 点到谁，谁就会被自动拉进会话（聊天里会出现一行「总管 把 架构师 拉进了会话」），然后执行任务。所以你不需要事先想好要哪些智能体参与，交给总智能体判断即可。

### 领头人自己新建智能体

如果现有的智能体里没有合适的人选，领头人可以在回答过程中当场定义一个新的。它在回复里写：

```
<agent name="名字" description="一句话说明它负责什么">你是……（它的身份、专长、做事方式和说话风格）</agent>
```

名字、简介、角色设定都由领头人自己写。新智能体会立刻加入会话（聊天里出现「总管 新建了智能体「俳句诗人」并拉进会话」），领头人可以在同一条回复里接着用 `@名字：任务` 给它分派。领头人的那条消息下方会列出新建的智能体，点「查看设定」可以看到并修改它写的角色设定。

- 新智能体只属于这个会话，沿用领头人的渠道和模型，也继承领头人「禁止本地操作」的设置。
- 觉得它好用，可以在会话设置里点「加入全局」，之后别的会话也能用。
- 一次回复最多新建 3 个，一个会话里最多 8 个；重名时直接使用已有的那个。
- 这依赖领头人按格式输出，建议领头人使用能力较强的模型。

你自己手动新建也一样自由：会话右上角的加号打开新建窗口，默认就是「自己设定」，模板只是可选的预填。

要点：

- 只属于某个会话的智能体不会被拉到别的会话。
- 没有任何可调度的智能体时，总智能体就按普通的一对一对话工作。
- 想自己挑选成员和协作方式，用会话列表上方的「自选智能体建群」。
- 开启了本地操作时，总智能体可以在同一轮里既操作又分派。见 [本地操作](local-access.md)。

## 点名

任何协作方式下，都可以在输入框下方（或宽屏右侧的团队面板）选中一个或多个智能体，这一次就只有它们按顺序发言，不受协作方式和轮数的影响。领头统筹下点名会绕过领头人。

## 不发言，让它们继续

输入框留空时发送按钮会变成「继续」：不产生用户消息，直接再跑一轮。配合点名可以让某个智能体单独补充一句。

## 停止

生成中随时可以停止。已经生成的内容会保留；还没轮到的智能体不再发言。

服务在一轮进行到一半时被停掉（关机、重启、更新），下次打开这个会话会提示「上次服务停止时，这里的回复还没完成」，点「继续」接着做，或者点「不用了」关掉提示。
