# 本地操作

允许智能体在这台机器上执行命令、读写文件。默认关闭；开启后，每个操作默认仍要先经过你同意。

**所有相关设置都在界面的「设置」页里，改动立即生效，不需要编辑任何配置文件。**

## 开启

两个入口，任选其一：

- **设置页**：左侧导航 →「设置」→ 打开「允许智能体请求本地操作」。
- **会话里直接开**：会话顶部有一个显示当前状态的按钮。关着的时候它显示「本地操作：关」，点一下确认即可开启，不用离开对话。

开启后再发一次消息，智能体就知道自己可以操作这台电脑了。

## 工作区

所有会话里智能体创建和读取的文件都放在同一个文件夹，命令也在这里执行。默认是程序目录下的 `workspace`。

在「设置 → 工作区」里可以：

- 看到并修改文件夹位置（填完整路径，不存在会自动创建；已有文件不会被搬过去）
- 复制路径，或在这台电脑的文件管理器里直接打开
- 查看工作区里现有的文件（点文件名复制它的完整路径）
- 决定是否允许读写工作区之外的文件

## 审批

智能体请求操作时，会话里出现一张卡片，写明：

- 要执行的命令，或要读写的文件
- **完整路径**：写入位置 / 文件位置（读写文件时），或执行目录（执行命令时），可一键复制
- 写入文件时，可以展开查看将要写入的全部内容

四个选项：

| 选项 | 效果 |
| --- | --- |
| 不允许 | 不执行，并告诉智能体被拒绝了，它会换办法或说明情况 |
| 允许一次 | 只放行这一个操作 |
| 允许五次 | 放行这一个，以及本会话里接下来的四个操作。剩余次数显示在会话顶部，可在会话设置里收回 |
| 永久允许 | 这个智能体以后的本地操作都不再询问（在任何会话里）。可在「设置 → 已永久授权」或智能体的设置里撤销 |

卡片执行后会注明这次是以哪种方式获得授权的。

另外两个不经过卡片的开关：

- 「设置」里把「没有预先授权时」改成「全部自动允许」：所有智能体的所有操作都不询问。
- 会话设置里的「本会话的本地操作不再逐条询问」：只对这一个会话生效。

想让某个智能体永远不能提出操作请求，在它的设置里关掉「可以请求本地操作」。

## 它能做什么

| 操作 | 模型写法 | 说明 |
| --- | --- | --- |
| 执行命令 | `<run>命令</run>` | Windows 用 `cmd.exe`，macOS / Linux 用 `/bin/sh`；在工作区里执行 |
| 读取文件 | `<read>路径</read>` | 相对路径以工作区为起点；默认只能读工作区之内 |
| 写入文件 | `<write path="路径">内容</write>` | 默认只能写工作区之内，会覆盖同名文件 |

用文本标签而不是各家模型的原生工具调用，是为了让五种连接协议和本地小模型都能用同一套机制。

## 谁可以改这些设置、谁可以用

本地操作等于让模型在你的机器上跑命令，所以有两条保护：

1. **改权限类设置**只能在运行程序的这台电脑上进行；或者在设置了访问口令之后，由输入过口令的设备进行。
2. **开着本地操作、又没有访问口令时**，只有这台电脑上的浏览器可以发消息和审批，手机等其他设备暂时只能查看。在「设置 → 访问口令」里设一个口令，其他设备就恢复正常。

这样你在自己电脑上点一下就能用，同一网络里的其他人却没法借机在你电脑上执行命令。

## 限制与边界

- 「允许读写工作区之外的文件」只约束**读写文件**的路径。**命令本身不受目录限制**：一条被你允许的命令可以访问当前用户能访问的任何东西。审批时请看清命令内容。
- 单条命令有最长执行时间（设置页可调），超时终止；输出过长会被截断。
- 命令不能交互（标准输入是关闭的）。
- 小模型可能不按格式输出标签、编造执行结果，或者在不需要动电脑的任务里多此一举地请求操作（实测 0.6B 的模型偶尔会这样）。建议给需要操作的智能体配能力较强的模型，并在小模型智能体的设置里关掉「可以请求本地操作」。
- 智能体读到的文件、命令输出、其他智能体的发言都可能包含诱导它执行危险命令的内容。处理不可信内容时不要用「永久允许」或「全部自动允许」。

## Docker 里

容器里的智能体**只能操作容器内的环境和挂载进来的工作区，管不了宿主机**。界面上会标注「容器内操作」，给模型的提示词里也会说明，让它在遇到管理宿主机的需求时如实告知。

容器里分辨不出哪台是「本机」，所以 Docker 部署需要先设置访问口令（设置页里设，或用环境变量 `MAC_TOKEN`），本地操作才会生效。

需要智能体管理电脑本身时，请用 `python run.py` 直接运行。

## 用配置文件预设（可选）

不想每次部署都点一遍的话，`config.yaml` 的 `local_access` 段可以给出默认值，环境变量 `MAC_LOCAL_ACCESS=1` 也可以。在设置页改过的项以设置页为准。
